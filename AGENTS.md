# Baltic Culture Site — project instructions

These styling rules apply only to this repository.

## Frontend styling

- Always use Tailwind CSS utility classes for new or modified frontend styling instead of handwritten CSS.
- Use Tailwind responsive, state and arbitrary-value utilities for layout, typography, colors and visual effects. Do not add custom CSS stylesheets, component style blocks or inline CSS for page/component styling.
- Keep CSS files limited to framework-required Tailwind imports and theme configuration when needed.
- When changing an existing component that uses custom CSS, migrate the styles affected by the task to Tailwind. Avoid unrelated wholesale refactors unless requested.
